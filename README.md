
# Etch-a-Sketch

A browser-based Etch-a-Sketch application built with HTML, CSS, and JavaScript as part of The Odin Project Foundations curriculum.

## Features

- Initial 16 × 16 grid.
- Dynamic grid generation using JavaScript.
- Adjustable grid size (from 1 × 1 to 100 × 100).
- Random pastel colors when hovering over squares.
- Progressive darkening effect with each interaction.
- Responsive square grid layout.
- Custom pastel gradient background.

## Built With

- HTML5
- CSS3
- JavaScript

## What I Learned

- DOM manipulation.
- Creating and removing HTML elements with JavaScript.
- Using event listeners.
- Working with CSS Flexbox.
- Using CSS custom properties.
- Handling user input and validating values.
- Generating random colors with JavaScript.
